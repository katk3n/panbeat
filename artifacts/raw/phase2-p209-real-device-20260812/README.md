# P209 real-device evidence

The JSON diagnostic files in this directory were generated by the prepared P209 build and must not be edited.

- `device-diagnostics.json`: MN-10 present at launch; Ding and both Slap inputs mapped.
- `connect-after-launch-diagnostics.json`: no device at launch; same-process reopen remained `no_ports` after connection.
- `relaunch-recovery-diagnostics.json`: relaunch with MN-10 connected recovered input; Tone, Ding, and both Slap inputs mapped. A later same-process reopen again recorded `no_ports`.

Together these runs verify connected launch, disconnected launch, physical connection/reconnection, mapped input, failure history, and the documented relaunch recovery. Godot 4.6 on this setup did not rediscover MN-10 after `close_midi_inputs` / `open_midi_inputs` in the same process. This remains an explicit product limitation rather than being reported as successful reopen recovery.
